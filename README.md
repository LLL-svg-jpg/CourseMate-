# CourseMate 刷课陪伴助手

自动播放课程 → 弹出题目时暂停 → AI 理解题意作答 → 关闭弹窗 → 继续播放。

不是"盲选两个选项把弹窗点掉"，而是真的读懂题目再作答；也不是纯协议模拟，
浏览器就在你眼前跑，进度看得见。

## 快速开始（图形界面，推荐）

### 1. 环境要求

- Python **3.11+**（用到标准库 `tomllib`）
- 已安装 Chrome 或 Edge

### 2. 装依赖：双击「安装依赖.bat」

只需要做一次。脚本使用清华镜像，速度较快。

失败的话手动执行：

```bash
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```

默认使用你系统里已装的 Chrome，**不需要**再下载 Playwright 自带的浏览器内核。

### 3. 打开软件：双击「CourseMate.pyw」

界面就是软件本体，不需要命令行。若双击没反应（`.pyw` 没关联到 Python），
改双击「**启动.bat**」。

界面分三个标签页：

| 标签页 | 填什么 |
|---|---|
| **课程** | 课程地址（一个地址一个框，点「＋」加一行）、倍速、静音、限时、账号密码 |
| **AI 答题** | 开关、API Key、模型、是否自动提交、题库缓存 |
| **高级** | 浏览器选择与路径、日志级别、验证码响铃 |

填好点「**▶ 开始刷课**」即可，日志区实时显示进度。中途想停就点「■ 停止」，
最多几秒内收尾退出。配置会自动保存到 `config.toml`，下次打开自动带出。

**关于账号密码**：可以完全不填。首次运行时在弹出的浏览器里手动登录一次，
程序会保存 Cookie，以后免密。

**关于 API Key**：不填也能跑，只是遇到题目会停下来提醒你自己处理。
也可以改用环境变量，避免密钥落盘：

```bash
setx ANTHROPIC_API_KEY "sk-ant-..."
```

### 命令行方式（可选）

不想要界面的话，命令行入口依然保留：

```bash
python main.py --check
```

自检通过后 `python main.py` 即可。两种方式共用同一份 `config.toml`。

## 它是怎么工作的

主循环只负责一件事：推进章节，让进度往前走。其余四件事交给常驻协程并行盯着：

```
主循环  ──  遍历章节 → 进入 → 轮询进度 → 播完切下一节
                      ↑
后台协程（并行常驻）  │
  playback_worker  ──┤  视频被暂停就恢复播放
  tuning_worker    ──┤  持续锁定倍速与静音（平台会偷偷重置）
  question_worker  ──┤  检测弹题 → 查缓存 → 问 AI → 填答案 → 关窗
  captcha_worker   ──┘  检测人机验证 → 暂停计时 → 等你手动处理
```

**答题闭环（试到对为止）**：

```
检测到弹题 → 提取题干与选项 → 拿一个起点答案
                                ├─ 本地题库命中 → 直接用（零成本）
                                └─ 未命中 → 问 AI（结构化输出强制 JSON）
     ↓
生成尝试序列（最可能对的排前面）
   单选/判断：AI 答案 → 其余选项按页面顺序
   多选：AI 答案 → 与它只差一个的组合 → 其余组合
     ↓
逐个尝试：清空已选 → 点选 → 提交 → 读平台反馈
   ├─ 判定正确 → 写回题库（标记 verified）→ 点确认 → 继续播放 ✓
   ├─ 判定错误 → 换下一组
   └─ 无法判断 → 立即停手，不乱点
     ↓
超过 20 次或 5 分钟仍未答对 → 放弃本题，强制关窗继续播放
```

**为什么必须试错而不是只答一次**：答错的题平台会重新弹出。
只答一次就关窗，同一道题会无限重弹，表现出来就是"视频卡住不动"。
逐个试到平台判定正确，才能真正把播放推进下去。

**试出来的答案比 AI 猜的值钱**：经平台验证的正确答案会以 `verified`
覆盖写回本地题库，下次遇到同题直接命中，一次都不用试。

**为什么自带 SQLite 题库缓存**：同一门课的弹题高度重复，第二遍刷几乎零 AI 调用成本，
而且离线也能答。

**计时补偿**：答题和人机验证的等待时间会从"有效学习时长"里扣掉，
否则设了 `limit_max_minutes = 60`，可能其中二十分钟花在等你处理验证码上。

## 已支持平台

| 平台 | 支持情况 |
|---|---|
| 知道智慧树 | 刷课 + 答题 |
| 超星学习通 | 刷课 + 答题 |

智慧树同时在跑好几套播放页，DOM 结构并不一致。硬认一个选择器等于把成功率押在运气上，
所以章节列表改成按 `LESSON_CANDIDATES` 候选列表依次尝试，命中哪个就用哪个，
并把实际命中的选择器打进日志——万一没命中，日志会直接告诉你该补什么。

新增平台只需在 `coursemate/platforms/` 加一个文件，实现 `PlatformAdapter` 契约，
再到 `platforms/__init__.py` 加一行 import，核心逻辑不用动。

## 已知限制

**必须说清楚的几点：**

1. **真实课程页上的完整流程没有端到端跑通过。** 登录、章节识别、播放推进、
   弹题捕获这条链路依赖平台当下的页面结构，需要有账号的人实际跑一遍才算数。
   若章节列表识别不出来，程序会把页面结构导出到 `runtime/page_dump_*.txt`，
   照着里面的实际 DOM 补选择器即可。

   已经验证的是 333 项测试，覆盖题目指纹、答案缓存、选项匹配与回退、计时补偿、
   配置热重载与往返、平台路由、契约完整性、协程异常分类、选择器多候选回退、
   停止信号中断、试错序列排序与去重、试错循环收敛（含永远答错时能否退出）、
   界面布局与滚动、退出后不留后台进程（这一项会起真实浏览器）、打包产物身份。

   ```bash
   for f in core adapters runtime retry providers urllist gui_layout shutdown packaging; do python tests/test_$f.py; done
   ```

2. **试错模式必然会提交答案。** 不提交就拿不到平台的对错反馈，无法判断该不该换下一组。
   这是"试到对为止"的内在要求，不是可选项。若不希望自动提交，
   在「AI 答题」页关掉"答错自动重试"，会退回"只填一次不提交"的保守模式。

3. **答对的判定依赖平台反馈。** 判据按可靠性排序：弹窗自己消失（最可靠）→
   选项上的对错样式 → 提示区文字。三者都读不出结果时程序会**立即停手**并记入日志，
   而不是继续乱点。

4. **不做验证码破解。** 检测到人机验证一律暂停并交还人工，同时把等待时间
   从学习时长里扣除。这是刻意的选择，不是没实现。

5. 浏览器窗口最小化可能导致播放进度不累加（平台的可见性检测所致，
   已注入可见性伪装缓解，但不保证对所有平台有效）。

## 项目结构

```
CourseMate.pyw              图形界面入口（双击打开）
启动.bat                    .pyw 未关联 Python 时的备用启动方式
安装依赖.bat                首次使用装依赖
main.py                     命令行入口与环境自检
config.example.toml         配置模板
coursemate/
├── gui.py                  tkinter 图形界面
├── config_writer.py        配置写回（标准库只能读 TOML，写要自己来）
├── config.py               TOML 配置 + 热重载（跑着改倍速立即生效）
├── logger.py               彩色控制台 + 文件日志
├── browser.py              Playwright 启动 / Cookie 持久化
├── stealth.py              自动化特征抹除
├── events.py               中断信号 + 学习计时补偿
├── workers.py              四个常驻协程
├── runner.py               刷课主循环
├── answer/
│   ├── base.py             题目/答案模型、指纹、归一化
│   ├── strategy.py         试错尝试序列生成
│   ├── ai.py               AI 作答（Anthropic SDK / OpenAI 兼容）
│   └── cache.py            SQLite 题库缓存
└── platforms/
    ├── base.py             适配器抽象与注册表
    ├── zhihuishu.py        知道智慧树
    └── chaoxing.py         超星学习通
tests/                      测试，不需要浏览器
docs/                       开源调研与架构设计
```
