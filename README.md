# CourseMate

**Windows 网课学习辅助工具 · v1.0.0**

使用 Python、Playwright 和 Tkinter，支持多账号管理、按课程地址绑定账号、独立登录会话，以及视频播放和部分答题流程。

[下载 Windows 版本](https://github.com/LLL-svg-jpg/CourseMate-/releases/latest)

## 快速开始

1. 在 Releases 下载 `CourseMate-v1.0.0-windows-x64.zip`，完整解压后运行 `CourseMate.exe`。保留同目录的 `_internal`，电脑需要安装 Chrome 或 Edge。
2. 在“课程”页粘贴课程章节目录首页或视频播放页的完整地址，每行一个。平台按地址自动识别。
3. 点击“新增”填写账号名称、登录账号和密码，并在每条地址右侧选择对应账号。也可留空凭据，在浏览器中手动登录。
4. 点击“保存配置”，再点击“开始刷课”。需要结束时点击“停止”。

“默认账号”是旧配置的兼容名称，没有内置账号或密码。新增后的账号可在“编辑账号”中修改。

## 平台与功能

| 平台 | 已适配的主要流程 |
| --- | --- |
| 智慧树 | 登录、共享课目录、视频播放、部分视频弹题与选择题流程 |
| 超星学习通 | 登录后进入个人空间、课程章节目录、视频、部分章节测验与独立考试页面 |
| 智慧职教 | SSO 登录、旧版学习空间目录、视频及 PPT/PDF 课件 |

- 多账号按地址绑定，切换时隔离浏览器会话。
- 登录与验证等待时限可在“设置 → 运行”中调整；超时跳过当前地址，继续下一条。
- 支持倍速、静音、字号调整、本地题库和运行日志。
- “AI 答题”可选择服务商、接口地址及模型；需要时自行填写 API Key，调用可能收费。

## 使用范围

课程章节目录首页与平台总课程列表是不同页面。当前仅适配部分页面结构；学习通直播、未知验证类型及智慧职教全部新版课程业务尚未覆盖。

登录和部分验证码自动处理已有有限真实样本验证，平台策略变化后仍可能需要人工处理。学习通视频弹题反馈、智慧职教弹题与 AI 作答仍有适配限制。正式考试请人工检查，默认不自动交卷。

本机测试、EXE 启动、真实认证和服务器学习记录是不同证据，不能据此保证整门课完成或学时被计入。字号更新仍可能有短暂重绘过渡，关于页的依赖检查按钮在部分启动中漏绘。

## 配置与升级

配置保存在程序旁的 `config.toml`，会话、题库和日志位于 `runtime/`。这些文件可能包含明文凭据，只留在本机，请勿上传或分享。

升级时先退出旧版本，解压到新目录，再按需复制自己的 `config.toml` 和 `runtime/`。保留旧版本便于回退；公开下载包不包含任何个人配置或登录状态。

## 源码运行

需要 Python 3.11 或更高版本，以及 Chrome 或 Edge：

```powershell
$env:PYTHONUTF8 = '1'
python -m pip install -r requirements.txt
python CourseMate.pyw
```

`安装依赖.bat` 仅用于源码环境，不能修复缺少内部依赖的 EXE。测试和交接材料仅保存在维护者本机；完整发布构建依赖本机测试资料。
