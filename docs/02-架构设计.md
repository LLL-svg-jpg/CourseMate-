# CourseMate 架构设计

## 一、定位

**自动播放课程 → 检测到弹题 → 理解题目并作答 → 关闭弹窗 → 继续播放** 的闭环陪伴程序。

与已有项目的差异点：

| 能力 | Autovisor | OCS | **CourseMate** |
|---|---|---|---|
| 弹题处理 | 盲选前两个选项关掉弹窗 | 依赖第三方题库 API | **AI 理解题意作答 + 本地缓存** |
| 反检测 | stealth.js ✅ | 页面内注入，易被探测 | stealth 注入 ✅ |
| 多平台 | 仅智慧树 | 7 平台（TS） | 适配器模式，Python |
| 提交策略 | 无 | 覆盖率阈值 | **默认只填不交，可配置** |

## 三、并发模型

Autovisor 的核心洞察：**主循环轮询进度，后台协程各司其职，用 `asyncio.Event` 协调暂停**。

```
main
 ├─ 主循环 learning_loop        轮询学习进度，直到 100%
 └─ 后台协程（并行常驻）
     ├─ playback_worker         检测 video.paused → 恢复播放
     ├─ tuning_worker           静音 + 锁定倍速（对抗页面重置）
     ├─ question_worker         ★ 检测弹题 → 作答 → 关闭
     └─ captcha_worker          检测人机验证 → 暂停计时 → 等人工完成
```

**计时补偿**：验证/答题期间的耗时从"有效学习时长"里扣除，
避免 `limit_max_minutes` 被非学习时间吃掉。

## 四、答题闭环（本项目核心增量）

```
question_worker 轮询命中弹题
   ↓
adapter.extract_question(page)      平台适配器提取题干/选项/题型
   ↓
AnswerCache.get(hash(题干))         本地缓存命中？→ 直接用
   ↓ miss
AnswerProvider.solve(question)      AI 作答，强制 JSON 输出
   ↓
adapter.fill_answer(page, result)   按题型点选/填空
   ↓
AnswerCache.put()                   写回缓存，下次零成本
   ↓
auto_submit ? 提交 : 仅保存         默认 false
   ↓
adapter.close_dialog(page) → event.set() → 主循环恢复计时
```

**为什么自带缓存**：同一门课的题库高度重复，缓存把 AI 调用量压到接近一次性成本。

## 五、平台适配器

抽象基类 `PlatformAdapter` 定义契约，每个平台一个子类，只写选择器和差异化流程：

- `match(url)` — 认领 URL
- `login()` / `is_logged_in()`
- `iter_lessons()` — 遍历章节
- `get_progress()` — 读进度
- `detect_question()` / `extract_question()` / `fill_answer()` / `close_dialog()`

新增平台 = 新增一个文件，不动核心。

## 六、目录结构

```
coursemate/
├── config.py       TOML 配置 + 热重载
├── logger.py       彩色控制台 + 文件日志
├── browser.py      Playwright 启动 / stealth / Cookie 持久化
├── events.py       暂停事件 + 计时补偿
├── workers.py      四个常驻协程
├── answer/
│   ├── base.py     Question / AnswerResult 数据模型
│   ├── ai.py       AI 作答（Anthropic / OpenAI 兼容双端点）
│   └── cache.py    SQLite 题库缓存
└── platforms/
    ├── base.py     PlatformAdapter 抽象
    ├── chaoxing.py 超星学习通
    └── zhihuishu.py 智慧树
```

## 七、合规

- 默认 `auto_submit = false`：只填不交，由使用者过目确认
- 不实现绕过人脸识别、不实现"暴力秒刷"、不伪造签到
- 遇人机验证一律**暂停并交还人工**，不做自动破解
